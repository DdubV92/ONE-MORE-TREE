# ONE MORE TREE LATEST BUILD PHASE 12

The download link is in the session message (GitHub Actions artifact "ONE MORE TREE LATEST BUILD PHASE 12 - build N (Windows)").

Extract the zip to a new folder and run `OneMoreTree.exe`. If SmartScreen warns, choose More info, then Run anyway.

## New in Phase 12

- **Dense island (new campaigns):** exactly 10,000 trees in groves, copses and glades, with an understory of hazel, bramble, juniper, bracken, sedge and fallen deadwood. About one tree in five has thick low boughs.
- **Ground you can use:** hummocks, small ridges, gullies, rock shelves and boulder clusters. There are 60 rock hides: a recess has one way out; a gap has two.
- **Hiding is real geometry:** rock blocks the hunter's view; an opening doesn't. Dense brush thins its view at a distance but not up close or when you run, and pushing through brush rustles.
- **After clearing,** the shrubs, rocks and hides stay.
- **Your Mixamo animations:** the crew walks, runs, sits, drives and sleeps with your captured clips, fitted to each body.
- **Proper fabrics:**
  - a leather sofa;
  - cotton sheets and wool blankets;
  - a vinyl shower curtain;
  - linen curtains;
  - wool work jackets.
- **Saves:** existing saves keep their old island and rules. Only new campaigns use the new island.
- **Review:** Preview (title screen) → Tab → "Phase 12 dense island, cover & motion".

**Checks:** see PHASE12_NOTES.md. Visuals were checked on a software renderer only.
