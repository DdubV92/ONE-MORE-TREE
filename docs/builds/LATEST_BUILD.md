# ONE MORE TREE LATEST BUILD PHASE 9

The download link is in the session message (GitHub Actions artifact "ONE MORE TREE LATEST BUILD PHASE 9 - build N (Windows)"). The title screen footer shows the same label.

Extract the zip to a new folder and run `OneMoreTree.exe`. If SmartScreen warns, choose More info, then Run anyway. Saves from Phase 8 load as they are (the new first-day guide is skipped for them).

## New in Phase 9

- **Main menu:** Continue (your latest unfinished game, with its state), New Campaign (a short brief; asks before replacing a slot), Load (state, logs delivered, save time, checkpoints), Settings, Help & Controls, Credits.
- **First-day guide:** in-world steps that finish when you actually do things: walk, journal, crew and dog, rack, fell, cut, carry, deliver, wages, night rules, sleep. Skip or replay it from Journal → Help & log.
- **First night:** you see the night rules (paused) before anything can catch you.
- **Messages:** important warnings can't be buried by minor ones; repeats collapse; the log is in the Journal.
- **Keys:** every key can be rebound (Settings → Key bindings); prompts show your keys.
- **Accessibility:** text size, captions, subtitles, hints, highlight strength, plus the Phase 8 comfort options.
- **Endings:** a one-time message when the last tree falls, saying what's left. A success summary from your real ledger, then return to the menu or keep exploring. Clearer hunt rules, survival status, leave-behind choice and escape summary.
- **Help:** full controls, contract, night and pause rules in the menu and the Journal; a player guide in docs/PLAYER_GUIDE.md.
